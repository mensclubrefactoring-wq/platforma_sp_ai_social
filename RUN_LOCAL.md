# Инструкция по запуску (Микросервисы на Go)

Теперь платформа работает на микросервисной архитектуре. Это позволяет масштабировать отдельные компоненты (например, AI сервис) независимо от остальных.

## Структура микросервисов
- **Gateway (порт 3000)**: Основная точка входа. Проксирует запросы к нужным сервисам и раздает фронтенд.
- **Auth Service (порт 3001)**: Регистрация, логин и проверка пользователей.
- **Tasks Service (порт 3002)**: Работа с задачами социального партнерства.
- **AI Service (порт 3003)**: Интеграция с ИИ (Gemini, OpenAI и др.).

## Предварительные требования
1. Go 1.21+
2. Node.js (для сборки фронтенда)

## Запуск

### 1. Сборка фронтенда
```bash
npm install
npm run build
```

### 2. Запуск всей системы
В корневой папке выполните:
```bash
go run main.go
```
Этот процесс автоматически запустит все микросервисы и Gateway.

## Изоляция данных
Каждый сервис имеет свою базу данных для лучшей изоляции:
- `db_auth.json` — пользователи.
- `db_tasks.json` — задачи.

## Как изменить AI модель
Все настройки производятся через переменные окружения в файле `.env` (см. `AI_CONFIG.md`). AI-сервис подхватит изменения при перезапуске.
