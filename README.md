# Platforma SP - Платформа социального партнерства

Инновационное решение для взаимодействия крупного бизнеса и социальных предпринимателей.

## О проекте

Platforma SP — это мост между корпоративным сектором (ESG-стратегии, КСО) и социально-ориентированным бизнесом. Платформа автоматизирует процесс создания задач, подбора исполнителей и генерации профессиональных коммерческих предложений с помощью ИИ.

## Технологический стек

### Backend (Серверная часть)
- **Язык**: Go (1.21+)
- **Framework**: Gorilla Mux (Роутинг)
- **ORM**: GORM (Object Relational Mapping)
- **База данных**: PostgreSQL (для хранения пользователей, задач и истории чата)
- **Безопасность**: JWT (JSON Web Tokens), Bcrypt (хеширование паролей)
- **Валидация**: govalidator (проверка email и данных)
- **Интеграции**: OpenAI API / DeepSeek API (через прокси на Go)

### Frontend (Клиентская часть)
- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS (современный адаптивный дизайн)
- **Анимации**: Motion (Framer Motion)
- **Иконки**: Lucide React
- **Роутинг**: React Router v7

## Основные возможности

1. **Многоуровневая авторизация**:
   - Роли: Бизнес, Предприниматель, Админ.
   - Обязательная проверка телефона и согласие на обработку данных (проверка на "реального человека").
2. **Маркетплейс задач**:
   - Поиск и фильтрация задач по категориям (Экология, Инклюзия и т.д.) и локации.
3. **AI Помощник (Smart AI)**:
   - Встроенный чат с сохранением истории в БД.
   - Автоматическая оптимизация описаний задач.
   - Классификация категорий задач на лету.
   - Генерация готовых коммерческих предложений для предпринимателей.
4. **Администрирование**:
   - База знаний (доступна только администраторам).
   - Портфолио предпринимателей для верификации и поиска.

## Настройка AI Моделей (DeepSeek / Gemini)

Платформа поддерживает гибкую смену поставщика ИИ через переменные окружения:

- **AI_PROVIDER**: `gemini` (по умолчанию) или `deepseek`.
- **AI_MODEL**: название модели (например, `deepseek-chat` или `gpt-4o`).
- **AI_BASE_URL**: URL API (например, `https://api.deepseek.com`).
- **GEMINI_API_KEY**: Ваш API-ключ.

## Установка и запуск (Локально)

1. Установите зависимости Go: `go mod tidy`
2. Настройте `.env` (см. `.env.example`).
3. Запустите сервер: `go run main.go`
4. Соберите фронтенд: `npm run build`

## Структура БД (PostgreSQL)

- `users`: Хранение профилей, ролей, телефонов и согласий.
- `tasks`: Социальные задачи от бизнеса.
- `ai_chat_messages`: История переписки каждого пользователя с ИИ.
