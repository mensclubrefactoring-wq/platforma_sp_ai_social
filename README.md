# Platforma SP - Платформа социального партнерства

Инновационное решение для взаимодействия крупного бизнеса и социальных предпринимателей.

## О проекте

Platforma SP — это мост между корпоративным сектором (ESG-стратегии, КСО) и социально-ориентированным бизнесом. Платформа автоматизирует процесс создания задач, подбора исполнителей и генерации профессиональных коммерческих предложений с помощью ИИ. Проект построен на принципах микросервисной архитектуры для высокой масштабируемости.

## Технологический стек

### Backend (Микросервисы на Go)
- **Язык**: Go (1.21+)
- **Архитектура**: Gateway + Domain-driven Services (`auth`, `tasks`, `ai`, `db`).
- **ORM**: GORM (Object Relational Mapping).
- **База данных**: **PostgreSQL** (Автоматическое создание таблиц при запуске).
- **Безопасность**: JWT для аутентификации, Bcrypt для хеширования паролей.
- **Интеграции**: Мульти-провайдерное ИИ (DeepSeek, Gemini).

### Frontend (Modern React)
- **Framework**: React 19 + TypeScript.
- **UI/UX**: Tailwind CSS (без курсива, чистая типографика).
- **Motion**: Framer Motion для плавных переходов.
- **Icons**: Lucide React.

## Основные возможности

1. **Многоуровневая авторизация**:
   - Поля: Email, Пароль, Телефон, ФИО представителя, Название компании.
   - Чекбокс подтверждения "Реальный человек" (Согласие на персональные данные).
2. **Маркетплейс задач**:
   - Функциональный поиск и фильтрация задач по категориям.
3. **AI Помощник (Smart AI)**:
   - История переписки сохраняется в PostgreSQL.
   - Генерация предложений (Proposal Generator) через модальное окно.
   - AI-Классификация категорий при создании задачи.
4. **Портфолио**:
   - Страница со списком предпринимателей, доступная админам и самим участникам.

## Конфигурация ИИ (DeepSeek / Gemini)

Платформа гибко настраивается через переменные окружения:

- **AI_PROVIDER**: `deepseek` или `gemini` (по умолчанию).
- **GEMINI_API_KEY**: Ключ для выбранного провайдера (DeepSeek API совместим с форматом ключей OpenAI).
- **AI_MODEL**: Название модели (например, `deepseek-chat`).
- **AI_BASE_URL**: URL API (например, `https://api.deepseek.com`).

**Пример для DeepSeek:**
```env
AI_PROVIDER=deepseek
GEMINI_API_KEY=your_deepseek_key
AI_MODEL=deepseek-chat
AI_BASE_URL=https://api.deepseek.com
```

## Установка

1. Установите зависимости: `go mod tidy` и `npm install`.
2. Настройте `DATABASE_URL` для PostgreSQL.
3. Запустите: `go run main.go`
4. Соберите фронтенд: `npm run build`
